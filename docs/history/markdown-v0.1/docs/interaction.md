# Runbook 页面交互设计

V0.1 使用一个资源列表页和一个工作区。工作区根据对象切换模板编辑、实例执行或历史查看，步骤的回显和轮次直接放在对应步骤内。

## 资源列表

列表分为“模板”“进行中”“已留档”三个视图，支持名称搜索。模板显示名称和更新时间；实例显示记录名称、来源模板、更新时间以及完成、失败、跳过、待处理和记录中数量。保存出错的当前对象显示错误提示。

主要入口为“新建模板”“导入”和模板上的“创建执行实例”。进行中实例点击后恢复工作区与上次选中步骤；已留档实例进入只读工作区。

模板提供重命名、归档和导出，模板列表支持已归档筛选及恢复入口。归档模板保留内容，在恢复前不能创建新实例。V0.1 用归档减少误删，已有实例依靠快照独立打开。

实例的“再次使用此流程”以该实例的当前流程创建全新实例，不继承结果和回显；“从原模板重新开始”使用模板的当前内容，两个入口明确区分。来源模板缺失时禁用后者并提示来源不可用；来源已归档时提示先恢复模板，前者仍可使用。

## 模板编辑工作区

可视化迭代默认打开“文档”：直接编辑排版后的正文，通过步骤、指令和变量控件操作；“源码”和“源码对照”保留为高级入口。详细交互和格式保留边界见[可视化编辑设计](../../../visual-editor.md)。下方源码转换操作适用于高级源码模式。

点击文档行时，在该行最左侧出现“＋”，就地选择正文、标题、列表、步骤、指令、人工检查点等元素。空行可直接转换；非空段落和卡片保留，在其后插入。新增步骤/检查点始终位于当前步骤之后，菜单会说明位置。滚动出视口时入口隐藏，归档对象不提供编辑入口。

```text
┌ 模板名称                  保存状态     导入  导出  创建执行实例 ┐
│ 原文编辑 / 文档预览 / 并排                                     │
├ 步骤目录 ───────────┬─────────────────────────────────────────┤
│ 检查维护窗口        │ CodeMirror Markdown 编辑器 / 阅读预览    │
│ 核对补丁包          │                                         │
│ 记录人工确认        │ 选区操作：转为步骤、转为指令、取消标记    │
└────────────────────┴─────────────────────────────────────────┘
```

粘贴 Markdown 后即可编辑和预览。首次点击“保存模板”填写名称并建立本地对象，之后自动保存。标题、列表和普通代码块按原文显示；只有人工标记过的内容进入步骤目录。

原文编辑区占据窗口剩余高度，长文档在区内显示纵向滚动条，支持滚轮、拖动滚动条和键盘定位。并排模式下原文与预览分别滚动，顶部工具栏保持可见；实例编辑使用相同布局。

“转为步骤”包裹完整 Markdown 块；部分块或嵌套范围无法安全转换时，提示选择完整顶层块。步骤可包含说明与多条指令。“转为指令”将普通段落中实际选中的文本包为代码围栏，或为已有围栏添加指令标记。连续段落内可以只选一行，前后说明原样保留在指令外，不必人为插入空行；若选区尚不属于步骤，合并完成步骤与指令转换。

预览中指令显示复制按钮，普通代码块没有 Runbook 指令操作。步骤标题由其首个标题或正文首行生成；改标题通过修改 Markdown 完成。移动、复制、移除和取消标记都提供可见入口，不要求用户手写 UUID。

“取消步骤标记”保留原始正文及代码围栏，移除该步骤的交互标记与指令标记；“移除步骤”则删除整个区段。两项操作使用不同文案。

模板草稿有效时自动更新可用文档，无效时显示“草稿已保存，尚未应用”和可定位错误。创建实例前等待保存并校验当前草稿；校验失败时停留编辑器，不静默使用旧内容创建实例。

选区工具增加“转为变量”，可选择指令里的主机、版本、路径等局部文本。对话框填写变量名，默认值初始为所选文本；也可引用已有变量。参数面板展示变量名称及默认值，不要求手写定义注释。创建实例对话框集中展示本次参数，初始使用来源默认值或来源实例自己的值。

## 实例执行工作区

```text
┌ 实例名称   进行中   完成 2  失败 1  跳过 0  待处理 3  记录中 0 ┐
│ 来源模板       已保存       调整流程     导出     结束并留档   │
├ 步骤目录 ───────────┬─────────────────────────────────────────┤
│ ✓ 检查维护窗口      │ 02 核对补丁包                            │
│ ! 核对补丁包        │ 说明、预期结果与指令正文                 │
│ ○ 记录人工确认      │ [复制指令]                               │
│                     │ [开始记录] [完成] [失败] [跳过]          │
│                     │ 回显文本 / 异常或跳过说明                │
│                     │ 本轮记录 / 历史轮次与更正                │
└────────────────────┴─────────────────────────────────────────┘
```

点击步骤只切换查看位置。“复制指令”提示已复制；页面不判断命令是否执行，不改变步骤状态。多条指令分别复制，V0.1 不默认拼接整步命令。

点击“开始记录”，或者第一次填写回显或说明，建立本轮草稿并冻结步骤快照。直接点击完成、失败或跳过也可在一个事务中创建并结束本轮记录，减少简单检查事项的操作负担。失败和跳过的说明不足时保留输入并提示补齐。

本轮回显支持粘贴、多行编辑、折叠和文本复制。已结束轮次只读；补充信息使用“追加说明”，误标结果使用“更正结果”，真正再次操作使用“重试”或“再次记录”。这些动作在历史中分别展示。

标记完成后可通过“下一未处理步骤”导航，保留当前结果反馈。失败时停留当前步骤。导航始终可手动跳转，不按依赖关系锁定步骤。

## 调整流程

调整流程复用模板编辑器，顶部显示“仅修改本次实例”和“应用并返回执行”。源码草稿自动保存，执行卡片继续对应已应用文档；编辑模式不提供旧指令的无提示复制入口。

实例执行区提供明确的“编辑实例”入口，与模板使用相同的 Markdown、指令、步骤重排、人工检查点和变量编辑能力。实例参数在该实例内编辑，文档与参数草稿一同保存。界面显示当前已应用值；历史轮次显示自己的冻结值。模板改名、改正文、改默认值或归档均不会覆盖它们。

应用前显示影响摘要：新增步骤、内容变化、移动步骤和移除步骤。内容变化的已记录步骤恢复待处理，移动步骤保留状态，移除步骤保留历史。正在记录的步骤若被修改或移除，要求先结束或作废该轮记录，原回显不会自动迁移到新指令。

摘要按本次参数替换后的正文计算。仅填写参数而尚未应用时，执行视图保留旧指令；应用失败保留输入供修正。离开编辑、放弃草稿和留档检查同时考虑参数和 Markdown，避免只保存正文却遗漏参数。

返回执行时存在未应用草稿，提供“应用修改”“保留草稿并查看已应用版本”或“继续编辑”。这是实例调整模式的退出选择，正常模板编辑无需每次手动应用。

## 留档和恢复

“结束并留档”显示完成、失败、跳过、待处理和记录中计数、已移除步骤数和可选的本次总结。含失败时标为含失败；含待处理时明确显示未完成并使用“结束并保留未完成记录”按钮。正在记录的轮次须先结束或作废。

存在未应用源码时，先返回调整模式应用修改，或明确放弃该草稿并恢复已应用文档，再进行留档。留档展示与报告统一对应最终已应用流程。

留档后冻结文档、结果和更正记录，工作区可以查看、搜索与导出。继续操作使用新实例，既有留档不会被打开为可编辑对象。

正常关闭窗口先刷新自动保存队列。失败时显示具体保存错误，并提供重试和导出未保存内容。异常退出恢复最后已确认保存的文档、回显草稿、当前步骤及未应用源码草稿；不会自动把草稿轮次标记完成。

## 导入和导出交互

导出菜单分别列出“普通 Markdown”“Runbook Markdown”“执行报告 Markdown”和“完整 JSON”，按对象提供可用选项。普通 Markdown 导出当前内容并移除交互标记，不表示回到首次导入时的内容；报告不会作为模板导出混入执行状态。导出报告时明确标示草稿轮次、失败与未完成步骤。

导入先显示格式、对象数量和校验问题。Markdown 导入建立新模板；执行报告作为普通内容处理，不推断历史。JSON 导入创建独立副本并保留原始来源标识，导入摘要列出新增对象，不提供默认覆盖。

详细状态定义以[执行记录模型](subsystems/execution.md)为准，保存与数据交换定义以[本地存储模型](subsystems/storage.md)为准。
