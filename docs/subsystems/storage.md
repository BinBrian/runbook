# 清单本地存储与存档

## 工作区

`native/runbook-checklist` 使用配置目录中的 `checklist.sqlite3`，SQLite WAL、synchronous=FULL、事务写入。工作区保存于单行 checklist_workspace.body；每次用例读取、验证并写入完整 Workspace。原生进程内互斥串行，前端也串行请求。

Workspace 包含 templates、instances、blocks；现有库缺少 blocks 时按空库列表读取，不为读取自动重写旧数据。新空工作区附带更新重启与玩家转区两种示例块。新实体/修改/导出使用清单格式 v2，已有清单 v1 按全局/无组读取，结果快照保留。

该模型面向首版个人小规模使用，未实现分页和增量写入。旧 runbook.sqlite3 保持原样，不迁移，不作为新状态来源。显式路径、环境变量及 AppLocalData 选择沿用启动模块；配置错误报错，不自动新建另一处工作区。

## 图片

文件位于 `checklist-images/<实例 ID>/images/<图片 ID>.<扩展名>`。身份和路径必须通过原生校验。只支持 PNG、JPEG、WebP、GIF，验证签名，每张不超过 8 MiB。读取只允许该实例已有条目引用的图片。

写入图片后提交数据库，失败清理本次文件；删除条目在事务确认后清理对应图片，意外残留的孤立文件暂不做全库定时回收。实例导入副本使用独立目录，修改副本补充材料不改变原实例。

## 导出与导入

模板和步骤块导出 .runbook.json；实例 .runbook.zip 只包含 runbook.json 和被引用图片。图片以包内相对路径关联，实例内有完整文档、步骤组、局部定义/值及记录，恢复不依赖原路径、原模板或块库。删除块定义不删除已有使用副本。

导入先解析校验，返回名称、类型、身份和重复提示；确认后提交。重复需明确 asCopy，生成新身份保留原记录。工作复制另走 create_instance，不带旧 entries。

限制为文件 32 MiB、解包总量 64 MiB。拒绝未知版本、非法引用、重复身份、非法顺序、缺失原因、快照不一致、路径穿越、重复ZIP条目、额外文件、缺图、无效图片和异常压缩包。导出通过自身导入校验，避免生成不可还原的存档。保存对话框通过临时文件、sync 与原子替换写入。

## 保存保护和恢复

React 编辑缓冲约 500ms 自动提交，成功后清脏；失败保持输入并显示错误。导航、关键动作、复制与正常关闭前刷新。显式参数修改经应用才生效，尚未提交评论等输入保留供处理。

异常退出只能保证已确认事务，未确认输入、突然断电和磁盘故障没有零丢失保证。完整备份使用实例ZIP；运行中仅复制数据库主文件不是完整备份，也不包括图片。

旧存储结构见[历史文档](../history/markdown-v0.1/docs/subsystems/storage.md)。
