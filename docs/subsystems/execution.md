# 线性执行记录模型

status 为 draft、in_progress、completed、terminated，archivedAt 独立。draft 集中填参，补齐所有引用参数后开始。每实例独立 currentStepId，切换实例不会改变它们的状态。

填参按全局、组内局部和步骤局部就近呈现，归属以 ID 确定；组不另设执行结果，currentStepId 始终指向具体子步骤。单层组聚合进度，切回实例展开当前所在组与步骤。

步骤结果仅提交到当前步骤。completed/skipped 推进，failed 停留；失败与跳过原因必填。最后一步完成或跳过自动 completed，留在当前列表，手动归档后才移入归档。终止需一次原因，不把未执行步骤改成跳过，不恢复原实例。

每条结果包含自己的 snapshot：渲染后的标题、说明、命令、当时参数值。历史不可改写或删除。已推进文档前缀冻结；当前步骤身份、位置固定而内容可改；后续可增删重排。更新参数须明确应用，只改变当前及后续显示，历史由 snapshot 展示。

已推进步骤的 groupId 和所属组元数据稳定，部分组内仍可修改后续成员。步骤推进后其局部值锁定，整组推进后组局部值锁定；部分组尚有后续步骤时可以应用组内新值，旧结果继续保留原值。全局变更同样只用于尚未推进的引用处。已推进引用过的参数定义冻结，防止通过改归属改变历史语义。

entries 按步骤归属保存结果、评论和图片。评论可编辑删除，图片可删除，补充材料可以在结束或归档后添加。保留 at 与 editedAt，编辑评论不会把它变成执行结果。

工作复制继承当前文档与参数值，清空 entries，从 draft 和第一步重新开始。存档导入副本则完整保留历史、状态和归档信息，使用独立本地身份和图片目录；这两个操作不可混淆。

原生状态规则和测试位于 `native/runbook-checklist/`。旧轮次/更正机制仅属[历史模型](../history/markdown-v0.1/docs/subsystems/execution.md)。
