# Windows Runbook 工作记录需求

当前产品以工作记录为中心，依据 [ADR 0013](decisions/0013-work-records-as-prototypes.md)；局部复用与多选合组依据 [ADR 0014](decisions/0014-favorite-steps-and-selection-grouping.md)。人工执行与本机草稿边界不变。

## 目标与边界

把已有维护流程变成可交互、可追踪、可留档的工作记录。直接新建工作，或打开任何已有记录“再做一次”。每份记录同时拥有自己的流程、参数和历史，不依赖单独维护的模板。

应用只复制命令，操作者在外部工具操作，再人工确认结果；不提供终端、不运行命令、不采集或自动判断外部结果。本地优先，不依赖登录、网络或模型服务。JSON 为内部内容结构，用户无需编辑源码。

## 新建与再做一次

新建工作直接得到可编辑的未开始工作，不需要选择模板。在待开始、进行中、已完成、已终止及归档的任何工作上，都可点击“再做一次”。

| 内容 | 新工作 |
| --- | --- |
| 步骤、组、说明、命令、变量定义及默认值 | 完整复制为独立可编辑内容 |
| 环境、区服、版本等已应用参数 | 默认带入供本次核对；可取消勾选，使用变量默认值 |
| 原工作未应用的输入草稿 | 留在原工作，不作为新工作的已应用值 |
| 完成、失败、跳过及当前步骤 | 重置，全部待处理，核对参数后显式开始 |
| 输出、结果备注、评论、图片、操作时间、终止原因、归档 | 留在原记录，新工作重新记录 |

来源仅用于追溯。新旧工作互不覆盖，任何一份又能成为另一份的原型；不存在“另存为模板”或向来源同步的操作。

## 内容与记录

| 能力 | 规则 |
| --- | --- |
| 步骤 | 标题、普通多行说明、零到多条命令；没有命令即人工检查点 |
| 命令 | 独立卡片、一键复制；每步记录统一结果，逐命令追踪可拆为一步一命令 |
| 参数 | 文本值，保留名称、说明、默认值；全局、组内或步骤局部，以稳定 ID 引用 |
| 引用 | 可用于标题、说明和命令；同一作用域共享填写，跨组同名仍独立 |
| 选区与插入 | 只替换当前选区；复制引用、输入 {{ 筛选已有变量，普通占位文字不自动绑定 |
| 步骤组 | 有标题与普通多行描述的单层连续子步骤；不增加依赖图或组级结果 |
| 收藏的步骤 | 从工作收藏单步或整组，搜索预览并从左＋插入独立快照；内容调整在工作内进行，再明确另存或更新收藏 |
| 线性推进 | 只向前，完成/跳过推进，失败停留；失败、跳过和终止原因必填 |
| 历史 | 每条结果保存当时已替换内容与参数，旧记录保留，已推进结果不改写 |
| 补充材料 | 评论与图片归属步骤，可追加；评论可编辑/删除、误贴图片可删除 |
| 图片 | PNG/JPEG/WebP/GIF，每张不超过 8 MiB；界面只显示添加图片 |
| 结束与归档 | 完成最后一步自动结束，仍留工作记录；手动归档才移入归档列表 |
| 终止 | 原工作不恢复，需要重做时再做一次，旧历史完整保留 |
| 多工作 | 可同时进行，各自保存当前步骤，切换不推进或终止其他工作 |
| 删除 | 详情更多菜单确认删除本工作，只影响自身及登记材料，不影响来源或其他快照 |
| 存档 | 工作完整 ZIP 含 JSON 与图片，收藏 JSON；重复导入为独立副本，不覆盖本地 |

## 编辑、参数与草稿

标题、说明和命令直接展示，双击或键盘原位编辑。左侧＋新增，右上⋯管理现有内容；左侧步骤导航用于定位/预览，状态色表达结果；右侧以紧凑变量树展示整份工作：全局变量在顶层用橙色，局部变量在组/步骤节点下用蓝色；平时只显示名称和值，单击选中、双击编辑，管理操作归 ⋯。唯一变量搜索位于右侧，同时筛选真实引用步骤，正文不再常驻搜索栏。参数修改仍须明确按范围应用。

未开始工作可自由调整流程。执行中当前步骤可改标题/说明/命令；后续可增删重排；已推进正文、命令、参数定义和结果冻结。历史参数按实际快照展示，后来的应用不重写过去。

点击未分组可编辑步骤的序号多选，Shift 连选；仅连续同级步骤可合组，当前及已推进步骤不参与。合组保持步骤身份、顺序、参数和材料归属，新增空标题/描述并聚焦标题。收藏保留原定义默认值，不带实际参数值或执行材料；插入单步变量归本步，整组保留局部范围，名称相同也不合并。来源、收藏、插入副本互不覆盖。

所有引用参数补齐后显式开始。参数改动按范围明确应用，其他范围草稿保留；完全推进的局部范围只读。复制命令使用已应用值或冻结值，不能偷用参数草稿。

未提交变量表单、参数、评论、原因和重做选项保留为本机草稿。关闭先刷新正文、保存草稿并正常退出，不自动应用或提交；顶栏草稿入口可回到原对象/步骤。只有实际写入失败提供重试或明确放弃后关闭。

## 已有内容与存档

原清单模板转换为未开始工作，默认值作为初始本次值；转换前原始工作区和身份映射同事务备份。已有实际工作及记录不变，重开不重复生成，删除转换项不重建。旧清单模板 JSON 导入为普通工作。旧 Markdown 库不读取、不迁移、不删除。

工作导出 .runbook.zip，包含 runbook.json 与 images/。完整导入保留原进度和材料；这与“再做一次”清空执行记录不同。工作和块的新写入继续使用格式 v2，内部 instance 字段仅为现有数据契约。

## 验收与后续

覆盖直接新建、流程编辑、填参/复制、失败重试/跳过/完成、评论图片、归档、两种参数选项的再做一次、双向隔离、完整存档独立还原、旧定义事务转换与草稿恢复、正常关闭重开。测试只使用隔离目录。

AI 仍为可选扩展，可自行配置远程服务或本地小模型；后续生成工作内容或建议参数必须经用户确认。本轮不接模型、便签、云同步、复杂依赖、独立阅读报告或 Markdown 兼容。
