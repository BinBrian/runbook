# 参数作用域与收藏步骤演示

本目录使用虚构环境和身份数据。命令仅为演示文本，用来展示变量作用域、复制和人工记录，不是实际业务操作指引。

- [更新重启服务](restart-services.runbook.json)：一个组内“环境”变量，四个子步骤分别展示停止、发布、同步和启动命令。插入后填写本次环境。
- [玩家转区](transfer-player.runbook.json)：本组环境、原区、目标区、玩家 ID 和平台账号 ID；六条命令与通知共用组内值，通知使用玩家 ID。
- [四环境独立使用](four-environments.runbook.json)：四组虚构环境为示例环境A `sandboxa`、示例环境B `sandboxb`、示例环境C `sandboxc`、示例环境D `sandboxd`。另有全局“环境=release”，四组命令引用各自的局部值。

两类收藏步骤使用 `formatVersion=2`、`kind=block`，导入到“收藏的步骤”。四环境文件沿用历史 `kind=template` 结构，当前导入为未开始的工作记录，并不提供独立模板页签。收藏步骤插入后生成独立快照，后续修改收藏不会覆盖已使用的内容。工作记录可通过“再做一次”继续复用，旧执行结果保留在原记录。

步骤组包含标题、普通多行描述和子步骤，复制与插入后保留。每个子步骤独立人工确认，应用不会执行命令。

在仓库根目录运行 `python scripts/generate-scoped-examples.py` 可生成本目录的 JSON，并同步[维护工作演示](../../../templates/release-maintenance/README.md)中的作用域与重启步骤。维护演示共 46 步、32 条命令、17 个参数；脚本核对纯文本演示基线的 28 条命令以及另外 4 条重启命令，只写仓库示例，不访问用户数据库。
