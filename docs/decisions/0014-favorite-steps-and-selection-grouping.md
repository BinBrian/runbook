# ADR 0014：收藏步骤与多选合组

状态：已采纳，2026 年 10 月 21 日。承接 ADR 0013 的工作中心模型，替代独立步骤块编辑页的产品入口。

## 决策

主导航使用“工作记录 / 收藏的步骤 / 归档”。收藏来自普通工作：从步骤或组的 ⋯ 保存单步或完整组，保留内容、变量定义和原默认值。已推进及结束工作也可收藏，不复制本次实填值、结果、评论、图片或操作时间。收藏页提供搜索、只读展开预览、来源定位、重命名、导出和移除，不再提供独立内容编辑器。需要调整时在工作中修改，再明确另存或更新已有收藏；更新保留收藏 ID 与创建时间，原工作及已插入副本不变。收藏名称与组标题是不同字段，重命名收藏不改组标题。

从左侧 ＋ 选择并搜索收藏，插入独立内容副本。单步插入当前位置之后，若在组内则加入该组；整组插到当前所属组之后，不制造嵌套。插入重建组、步骤、命令与参数 ID，引用按身份重绑，不按名称合并变量。单步捕获将所需全局/组变量归入本步骤；整组捕获将所需外部全局定义归入本组，保留各子步骤局部变量。定义默认值沿用原值，不拿已应用值或草稿冒充默认值。

工作内可点击未分组可编辑步骤的左序号多选，Shift 连选。就近固定工具条显示数量、合组和取消；非连续选择禁用合组，跨组/不可编辑边界的 Shift 范围整体拒绝，不静默跳过或重排。合并至少两个连续、同级、未分组步骤，新增一个空标题/描述组，展开并聚焦标题。步骤、命令、变量定义身份和执行顺序不变，参数值、评论和图片继续归属原步骤。执行中当前及已推进步骤不能参与，结束工作不能改结构；不增加组级结果、嵌套或依赖图。

## 数据与权威

收藏继续存于 `Workspace.blocks`，沿用 v2、kind=block 的自包含内容契约；增加可选 `favorite` 来源信息（kind、sourceWorkId/name、sourceStepIds、可选 sourceGroupId）。旧块无此字段按组收藏读取，无删除、迁移或改写。单步收藏在存储层仍有一个包装组，全部参数属于唯一子步骤；插入时去掉包装组。旧程序不承诺读取新增字段，当前导入器与原生校验支持完整 JSON 还原和重复副本。

`capture_favorite` 只接受已保存来源工作 ID 与步骤/组 ID，由原生读取权威文档并重绑身份；不接受前端任意快照或参数值。`rename_favorite` 只改名称。替换和移除使用原保存事务，失败不提交。来源可被移除，已收藏快照仍独立可用，来源元信息只作追溯。

合组由前端按最新文档/工作状态验证后进入原有 `save_instance`；原生继续裁决组连续性、当前步骤/冻结前缀及历史一致性，不引入第二套持久化路径。选中状态只属视图，不进入工作或存档。收藏名称及更新目标属于本机显式草稿，正常关闭可恢复，不自动保存收藏。

## 验证

定向覆盖单步/组捕获、默认值与作用域、独立插入/更新/移除、来源历史冻结、JSON 与 ZIP、正常退出重开、旧块读取、Shift/非连续/运行中选择、标题聚焦及两主题宽窄布局。当前结果和自动化边界见 [验证记录](../testing.md)。
