# ADR 0011：就地编辑与变量上下文

状态：2026 年 10 月 20 日已实现。验证证据与限制见[验证记录](../testing.md)。

## 问题

长步骤编辑时，回到文档前方查找变量会打断选区。常驻标题、描述标签和输入框也让清单更像表单；把“新步骤”等默认文字写入数据，会混淆真实内容与空内容。

## 决策

右侧面板独立于正文滚动，按全局、当前组、当前步骤展示变量。上下文优先使用有效编辑字段，否则使用浏览位置；实际执行位置保持独立。模板展示默认值，实例当前内容展示已应用值，已推进步骤展示结果快照；参数草稿只提示未应用。

复用按参数身份与所属范围校验，使用原字段保存的真实 Range。非空选区只替换当前一处，折叠选区插入变量标签；无有效目标时禁用，不退回任意字段末尾。字段卸载、只读、作用域变化或离开编辑上下文后清理目标；只有实际获焦点的字段能重新捕获选区，迟到事件不能恢复旧目标。面板和局部变量弹层可保留编辑位置。拖动选中文字后在其左侧提供“使用变量 / 新增变量”，分别展示可见作用域已有定义或新建表单；新建默认值来自选区，取消不改正文。

显式目录或缺参定位优先于滚动途中的阅读位置，下一次正文选择/滚动后恢复跟随。面板正在填值时，缺失项移除等正文布局变化不能切换作用域或卸载输入框。删除未引用变量后清除其失效草稿 ID，保留其他范围草稿，避免留下无法提交或取消的脏状态。

变量标签点击属于定位操作，与选区插入分开。定位同时携带稳定参数 ID、来源步骤和实际触发元素，重新校验该步骤可见范围，不按名称或旧编辑器的 Range 猜测目标。模板与块定位默认值定义，实例定位本次值，只读仅定位；面板展开、清除搜索、滚动高亮都不写业务数据。同一未提交定义可重复聚焦，其他未提交定义必须先保存或取消；实例各范围草稿保留，仍需显式应用。展示标签和编辑器中的标签均支持鼠标与键盘，拖动选择不触发；冻结历史普通文本不解析成引用。作用域标题的新增入口显示「＋ 新增」，沿用原归属与权限，避免仅图标难以发现。

实例待填摘要标签增加变量引用搜索，与正文标签的原位定位区分。点击摘要标签将稳定 ID 与展示命名空间带入固定搜索栏，仅展示并展开所有实际引用该 ID 的步骤和所属组，同时聚焦右侧本次值。手动输入按变量名称/命名空间匹配定义，再按引用查步骤，不搜索普通文字、不按归属猜使用位置。过滤保留原索引、顺序和权限，仅改变视图；清空、Esc、全流程主动导航或实际推进退出，存档和执行记录不携带搜索状态。历史结果仍使用冻结快照。参数未提交草稿不能因筛选、清空或隐藏步骤而丢失，应用继续按原完整作用域处理。

直接插入已有变量通过 `{{` 建议完成（2026 年 10 月 21 日按用户习惯调整，替代原 `/` 入口）。触发只来自实际键入，支持字段/行首及正文紧邻位置，不扫描已有文档或粘贴文本。查询与两个左花括号都是真实文本，明确选中候选时才替换捕获的本次查询 Range；取消不删文字，`{{名称}}` 不按名称自动解析。建议沿用当前可见参数身份与冻结边界，中文组合输入期间不接受 Enter，普通斜杠和路径保持原文；候选悬浮层沿用焦点保护与视口避让。

标题与描述默认展示，双击或 Enter/F2 原位编辑，沿用实时缓冲保存；失焦、Esc、多行 Ctrl+Enter 完成编辑，不回滚已输入内容。不再显示额外字段标签。组说明继续是普通文本，不增加变量解析。

步骤和组采用相同的双入口分工：左侧“＋”仅提供新增和插入，右上“⋯”提供复制、移动、转组/保存复用及末尾分隔的删除；这是 2026 年 10 月 21 日用户确认的语义调整。模板与块去掉重复“步骤 01”和常驻工具条，正文的组设置折叠区由组头菜单取代，标题与描述继续就地编辑。当前/后续/历史权限、同组移动、唯一块组及删除前的记录/草稿保护由原动作保持，入口位置不扩大可修改范围。结构菜单共用键盘、焦点和视口定位；内容收缩引发滚动校正只重定位，主动滚动继续关闭。

整项删除与步骤内编辑分开，放在模板、块、实例详情顶部更多菜单中，确认框显示已保存的实体名称和范围。刷新后按身份删除，目标显式草稿须先提交或取消，其他对象草稿保留。删除定义不追删使用副本；删除实例包含自身记录及登记图片，事务/文件清理边界见架构文档。对话框与工作区的 React key 采用不同命名空间，取消默认焦点、Tab 圈焦和忙碌状态不能触发背景页面操作。

模板、块与实例命令采用相同的单字段就地编辑，实例不切换整步“编辑 / 完成”模式。添加命令归入步骤左侧“＋”，新卡展开后直接编辑；移动与删除归入本命令右上“⋯”，移动只改变本步骤内的顺序、保留身份和引用。根据后续视觉确认，卡片保留浅灰操作栏与统一正文留白，但不显示命令标题/编号文字；复制入口独立保留并先刷新缓冲。定义展示变量名称，实例展示已应用值；原生权限和历史快照继续独立于编辑入口，完成/跳过推进后不可修改，失败记录仍保留原快照。

右侧变量行的文字复用入口改为小复制图标，写入带自有版本标记和稳定参数身份的 HTML 剪贴板片段，并带可读纯文本回退。粘贴只解析自有引用数据，重新校验可见 ID、作用域、只读状态与实际 Range；不按名称猜测、不自动新建参数、不插入外部 HTML。无效引用拒绝本次粘贴并保留原内容。普通纯文本继续按原保真规则粘贴，变量默认值、实例草稿和已应用值不因复制引用而修改。已有插件只增加 write-html 权限，不新增读取权限。

灰色占位只在视图出现。新步骤标题保存为 `['']`，空组名为 `''`，描述保存真实空值；仅组名放宽非空要求，仍校验 1024 UTF-8 字节和 NUL，其他实体与参数名称仍必填。格式仍为 v2，不改写已有文档、历史或旧库。编辑器忽略浏览器为空字段生成的占位 BR，保留真实文本换行和空格；上下文重渲染不重建未变内容 DOM，以免原 Range 失效。

## 边界

后续确认已将变量定义、本次值修改与按范围显式应用统一到右侧，移除正文重复入口。右侧搜索只过滤当前可见范围的名称、说明和显示值，不写业务数据；完整作用域应用/取消不能被过滤结果收窄，历史不使用后来值匹配，缺失定位清除右侧过滤。定义表单捕获原身份与归属；实例草稿仍独立保存，应用/取消只处理所选范围，默认值不随本次填写变化。缺失摘要现在同时驱动正文变量引用搜索和面板聚焦，正文内已有变量标签仍沿用原位定位。冻结、进度与存档仍由原生层裁决。未接入 AI、命令运行或同步服务；系统剪贴板和文件选择框验证范围单独记录，不以复制请求夹具宣称实际系统剪贴板已验证。
