# 参数与独立实例编辑

状态：已实现并验证。日期：2026 年 10 月 13 日。

## 已确认目标

模板中的固定内容可以选中转换成变量，以所选文本作为初始默认值。创建实例时填写本次参数；实例内可以继续改参数、Markdown、指令、顺序和人工检查点。模板用于复用，实例用于实际工作，两者共享编辑器但不共享可变数据。

用户确认实例参数修改需要显式应用；受影响步骤恢复待处理，旧轮次及当时参数保留。模板后续更新不覆盖任何已有实例。

## 内容与参数定义

变量定义作为单个顶层 JSON 注释放在 Markdown 内：

```markdown
<!-- runbook:parameters {"HOST":"staging.example","VERSION":"1.0"} -->

目标主机：{{rb:HOST}}
```

名称使用英文字母或下划线开头，后接英文字母、数字或下划线，最多 64 个字符。默认值是字符串，可以为空。`{{rb:NAME}}` 使用显式前缀，普通文档中的其他模板语法不参与替换。定义随 Runbook Markdown 导入导出，不依赖来源模板的数据库行。

替换保留值的原始字符，不递归求值，不做 shell 转义或执行。结构标记不能参数化，替换不得创建、删除、截断或改变步骤/指令身份；无法保持原结构的值拒绝应用。JSON 编码须避免值中的 `-->` 提前结束注释。模板与实例继续使用原生解析作为权威。

## 实例所有权

实例保存带占位符的原始文档和自己的参数值。创建时复制模板有效文档与参数默认值，合并本次填写值，并冻结在初始快照中。此后重新打开、恢复、编辑或执行都不向模板读取可变参数。再次使用实例时复制该实例自身当前文档和参数，不复制结果；从原模板重新开始才读取模板当前版本。

文档和参数都有草稿与已应用状态。自动保存保存草稿；显式应用原子更新有效文档、有效参数和替换后的步骤投影。修改已有变量的默认值不会重置已保存的实例值；新增变量使用自己的默认值。移除变量定义与占位符后，应用时清除已不使用的参数值。

轮次冻结替换后的步骤正文、指令及参数值。参数变化只有实际改变步骤内容时才增加步骤内容版本；无关参数或仅重排不撤销已有结果。对正在记录的步骤改内容或移除时仍须先结束或作废该轮次。旧轮次、旧参数和回显保持只读。

## 兼容与验证

数据库升级为 schema 2，升级已有 schema 1 文件前保存 SQLite 一致性备份；原记录不重新初始化。旧对象缺少参数字段时按空集合解释。完整 JSON 导出使用版本 2，同时接受合法的版本 1 备份；较新版本和不一致投影仍整包拒绝。

验证覆盖精确替换、非法结构拒绝、默认值、模板与实例双向隔离、实例参数草稿恢复、受影响步骤版本、旧轮次快照、重排/检查点、旧库升级和新旧备份。自动验证只使用隔离数据库，不修改用户当前工作区。

原生 58 项、前端 37 项测试通过；真实 WebView2 完成选区转变量、实例参数修改、重排、内容编辑及模板更新隔离检查。旧版 EXE 创建的数据库由新版打开后逐字段一致，升级备份保持 schema 1、SQLite integrity_check 为 ok，旧 JSON 可预检导入。详细证据见[验证记录](../testing.md)。
