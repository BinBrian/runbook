# 显式数据目录与启动诊断

状态：已实现。日期：2026 年 10 月 13 日。

## 原因

用户从资源管理器双击本机开发构建时，默认 AppLocalData 子目录创建返回 Windows 错误 5（拒绝访问）。早期隔离测试没有覆盖此默认路径，启动错误又在窗口出现前导致退出，用户只能看到窗口闪现。

## 决定

1. 每次启动在 EXE 同目录记录技术日志；不可写时回退到临时目录。初始化失败显示不依赖 WebView 的原生提示，不记录维护文档或执行正文。
2. 数据目录优先级为测试环境变量 RUNBOOK_DATA_DIR、EXE 同目录 runbook.local.json 的 dataDirectory、Tauri 默认 AppLocalData。前两者必须是非空绝对路径。
3. 配置存在但无效、无法读取或指定目录不可写时明确报错，不静默转到另一空数据库。默认目录不改，原有数据不迁移、不删除。
4. 当前开发副本显式配置为工程根 .local-data。配置由 scripts/configure-local-data.mjs 创建，脚本不覆盖已有不同配置；数据和本机配置不进入版本控制。业务数据与 target 构建产物分离。

## 代价与验证

清理 target 后需要再次执行配置脚本，或手动恢复本机配置。配置文件只负责路径，不包含数据库或维护记录。工程移动后需要更新绝对路径。正式安装仍可使用默认系统应用目录；此决策不放宽系统权限、不请求管理员启动。

目录优先级、非法配置和惰性默认解析由定向测试覆盖。当前机器在不设置 RUNBOOK_DATA_DIR 的情况下验证配置目录启动。用户数据目录的升级和迁移应作为显式操作实现，不能通过容错路径暗中换库。
