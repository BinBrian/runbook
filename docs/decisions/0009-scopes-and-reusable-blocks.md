# ADR 0009：参数作用域与可复用步骤块

状态：2026 年 10 月 20 日已实现并通过真实桌面闭环、两次正常退出重启验收。补充 [ADR 0008](0008-json-content-and-optional-ai.md)，复用同一需求规划；证据见 [验证记录](../testing.md)。

## 问题

维护演示流程包含三组玩家转区，以及 sandboxa/sandboxb/sandboxc/sandboxd 相同的四步更新重启。全部参数集中到顶部会混淆同名身份与环境；逐份重新编写命令也增加模板维护量。

## 决策

参数分为全局和局部。Parameter 的可选 ownerId 明确所属步骤或单层组，缺省表示全局；引用以稳定 ID 绑定，不按名称查找或隐式覆盖。一步只能访问全局、自身及所属组的局部参数。不同组可以显示同名“环境”“玩家 ID”。界面在流程顶部显示全局参数，局部参数放在对应组/步骤，开始前只汇总缺失项并可跳转；全部引用参数补齐后才开始。

文档仍用平铺 steps 确定线性执行顺序，附加 groups 元数据与 step.groupId。每组成员必须连续，组不嵌套；组只组织流程、共享局部参数和聚合进度，不增加独立结果。玩家组内的六命令/通知、更新重启块内的四命令均按具体子步骤分别记录。

组在产品中视为包含子步骤的步骤块，具备标题（沿用 name）和普通多行描述（可选 description）。描述属于文档快照，复制与复用完整保留，已有子步骤推进后与标题一同冻结；旧格式缺省为空，不为新增说明改写旧记录。

复用块作为独立 kind=block 文档存入 Workspace.blocks，包含一个完整组。块定义自包含，参数均为本组或子步骤局部参数。将已有组保存为块时，捕获引用到的全局定义为块内局部参数，保留原默认值，不带本次值或记录。插入时生成独立组、步骤、命令与参数身份并重绑引用；重复使用相同定义的实例值/结果互不影响。

块定义的修改不自动同步已有模板使用项或实例；sourceBlockId 只追溯来源。复制组同样建立独立身份和局部定义，保留默认值后重新填参，不继承执行历史。需要引用流程全局参数时，用户在可见范围内明确选择该全局引用。

formatVersion 升为 2。现有清单 v1 仍按缺省全局/无组读取，已有结果快照保留；新建/修改/导出按 v2。旧 Markdown 数据库不参与升级。模板/块导出 JSON，实例 ZIP 包含完整组与局部定义/值和图片，恢复不依赖块库。

## 冻结与代价

局部参数值可显式应用到所属范围内尚未推进的内容；单步骤已推进或整组已推进后，该局部值锁定。部分组仍可修改后续子步骤，旧失败及已推进结果保持原快照。保护已推进步骤 groupId 和所属组元数据、当前身份和位置，避免通过移组绕过冻结。

每次插入保存独立快照意味着文档中仍携带执行所需的具体命令内容。用户只维护一份复用定义，现有实例能够独立导出、回看和编辑。首版不引入引用自动升级、循环、条件分支、批量数据展开或命令运行。

## 验证要求

覆盖同名局部隔离、越范围引用拒绝、组连续性、复制重绑、块更新隔离、v1 历史保留、局部修改冻结边界、完整 JSON/ZIP 和真实桌面当前组恢复。以两种种子块、四环境示例及真实维护模板执行隔离验收，不执行示例维护命令。
