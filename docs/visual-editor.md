# 可视化 Runbook 编辑设计

## 目标与边界

默认打开可直接编辑的文档。正文呈现标题、列表和段落；步骤以有边界的卡片显示，指令有独立的命令编辑区域，变量以标签显示并连接参数面板。用户无需编辑文档头、注释标记或 UUID。命令本身始终可核对，不自动执行。

模板和实例复用同一编辑组件。模板保存可复用内容；实例保存自己的草稿，经现有“应用并返回执行”更新执行文档，受影响步骤恢复待处理，旧轮次不改写。

## 页面与交互

- 默认“文档”模式占用主编辑区，左侧保留步骤目录，顶部保留名称、保存状态、创建实例或应用按钮。
- 文档内支持标题、正文、加粗、斜体、有序/无序列表、引用及代码。工具栏和选区操作提供常用格式、设为步骤、转为指令、设为变量；新增步骤和指令无需先接触源码。
- 步骤卡片显示标题、步骤标识和移动入口，内部身份不直接呈现。移动步骤保持身份；复制须分配新身份。
- 指令卡片提供语言、准确命令内容、复制及变量入口；输入按纯文本处理，禁止富文本排版自动改写命令。
- 变量显示名称标签；在参数面板修改模板默认值或实例本次值，实例仍需显式应用。
- “源码”作为高级入口保留 CodeMirror 和现有转换能力；查看/切换模式本身不更改文档。
- 表格等本轮未支持直接编辑的结构按原文预览并提供源码入口；禁止静默丢弃或强制转换。
- 长文在文档面板内滚动，工具栏保持可见。只读对象保持只读。

### 当前行插入

点击正文时在该行最左侧显示“＋”，点击展开就地元素菜单，可选正文、标题、列表、引用、分隔线、步骤、指令、人工检查点和代码。空行输入 `/` 也打开同一菜单。顶部保留格式与选区转换工具，新增元素以行旁入口为主。

非空内容在所在段落或卡片之后插入，不切断命令或覆盖选区；空段落可直接替换。列表内以整个列表为插入边界。步骤内的指令与普通内容继续属于当前步骤；新增步骤或人工检查点放在该步骤之后。菜单说明插入位置，取消不修改内容。滚动与窗口尺寸变化时入口跟随内容，位置离开视口时隐藏；菜单避免越过窗口边缘。只读对象不出现入口。

## 数据与适配

数据流：SQLite Markdown → 前端编辑投影 → 可视化编辑事务 → Markdown → 现有原生解析/保存 → SQLite。前端文档树只用于编辑，原生仍裁决步骤、指令、参数和执行版本，不另建可变内容权威。

编辑投影保存原文片段与其内容签名。未修改片段逐字符回写；发生编辑的普通富文本片段可规范化 Markdown 排版。指令正文和保留块按原始字符串保存，步骤与指令身份作为节点属性维护。元数据保持在文档属性中，用户通过控件编辑。

高级源码有非法标记时显示诊断，保留原始草稿并限制依赖合法结构的可视化操作。选区转换、复制和拖动须保留或重新分配正确身份。粘贴外部 HTML 不执行内容、不加载外部资源。

步骤只能直属文档，指令只能直属步骤，普通富文本容器不能包裹步骤、指令或保留块。事务提交前检查序列化结果，拒绝会破坏这些边界的格式操作，原内容继续保留。

内部复制通过专用剪贴板格式保存结构与引用到的参数定义；粘贴生成新的步骤和指令身份。相同变量名与默认值可复用，同名不同默认值时拒绝整次粘贴并提示。外部纯文本 Markdown 可转为文档块，普通代码不会自动成为执行指令。外部 HTML 保留常用文字格式，移除资源与事件，未知容器展开为其正文。

## 验收

1. 默认文档模式不展示 Runbook 注释/UUID，正文可直接编辑。
2. 示例文档和参数文档仅打开/切换不改内容；未知结构保留原文。
3. 命令含空格、中文、反引号、CRLF/末尾换行时可精确保留；命令编辑不吞入说明。
4. 步骤移动/复制身份正确；创建实例、实例独立编辑、参数应用与旧历史保持原有约束。
5. 长文可滚动，撤销/重做可用，源码切换不丢未保存输入。
